# Analizador Inteligente de Contenido de Imágenes

Aplicación web full-stack que permite subir una imagen, la analiza mediante un
servicio de IA y muestra las etiquetas detectadas con su nivel de confianza.

> 🚧 En construcción — las instrucciones completas de instalación y uso se
> documentan al cerrar el desarrollo.

## Stack

- **Backend:** Node.js 22 · TypeScript · Express — arquitectura hexagonal (ports & adapters)
- **Frontend:** React 18 · Vite · TypeScript

## Estructura

```
├── backend/    # API REST (POST /api/analyze)
└── frontend/   # Interfaz de usuario
```
